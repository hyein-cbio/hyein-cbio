# Hyein Cho

Computational biologist interested in genomics, epigenomics, single-cell analysis, and scientific software.

I also tinker with AI-assisted development, developer tooling, and small utilities that make technical workflows a little less painful.

## 🧬 Computational biology & genomics

- [`epi-SHARE-seq-pipeline`](https://github.com/hyein-cbio/epi-SHARE-seq-pipeline) — single-cell / single-nucleus multiomic processing pipeline
- [`excluderanges`](https://github.com/hyein-cbio/excluderanges) — genomic range utilities
- [`PoincareMaps`](https://github.com/hyein-cbio/PoincareMaps) — experiments with Poincaré-map based visualization and analysis

## 📊 R & data science

- [`amap`](https://github.com/hyein-cbio/amap) — R-based data analysis and visualization
- [`ggvanced`](https://github.com/hyein-cbio/ggvanced) — multivariable visualization with `ggplot2`
- [`gbdmr`](https://github.com/hyein-cbio/gbdmr) — differential methylation analysis in R
- [`rtracklayer`](https://github.com/hyein-cbio/rtracklayer) — tools around genomic annotations and tracks

## 🤖 AI & developer tooling

- [`pi-compact-transcript`](https://github.com/hyein-cbio/pi-compact-transcript) — compact transcript tooling for Pi
- [`pi-export-notool`](https://github.com/hyein-cbio/pi-export-notool) — lightweight Pi export tooling
- [`pi-multilang-alias`](https://github.com/hyein-cbio/pi-multilang-alias) — multilingual alias helpers for Pi
- [`orca`](https://github.com/hyein-cbio/orca) — experiments with multi-agent coding orchestration

## 🗺️ Geospatial & web
